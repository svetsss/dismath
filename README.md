# Дискретная математика

Индивидуальные лабораторные работы, вариант 14.

## Содержание

- `lab2` — комбинаторика и рекуррентные последовательности;
- `lab3` — кодирование информации;
- `lab5` — систематические коды;
- `lab6` — алгоритмы на графах;
- `lab8` — транспортные сети;
- `lab9` — двудольные графы, максимальный поток и паросочетания.

Для запуска всей выбранной работы перейдите в её папку и выполните `python3 labN.py`.
Лабораторным №6, №8 и №9 для построения рисунков требуется Pillow:

```bash
python3 -m pip install -r requirements.txt
```

Лабораторные №4 и №7 были выполнены в группе и находятся в отдельных репозиториях.
