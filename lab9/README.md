# Дискретная математика — лабораторная работа №9

Вариант 14. Три программы по пунктам А, Б и В находятся в отдельных файлах. `lab9.py` запускает всю работу целиком, а `lab9_visualization.py` строит рисунок.

## Запуск всей работы

```bash
python3 -m pip install -r ../requirements.txt
python3 lab9.py
```

Каждый пункт также можно запустить отдельно: `task_a_bipartite.py`, `task_b_ford_fulkerson.py` или `task_v_kuhn.py`.
